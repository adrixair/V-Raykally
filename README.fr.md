## Votre premier rendu en quatre étapes

1. **Installez V-Raykally** avec le téléchargement adapté à votre plateforme.
2. **Connectez V-Ray Standalone.** Vérifiez le programme détecté dans les paramètres, ou sélectionnez-le manuellement.
3. **Ajoutez vos scènes.** Importez vos fichiers `.vrscene` ou `.vrs` et réorganisez les tâches selon vos priorités.
4. **Appuyez sur Play.** Suivez la progression, consultez les journaux et ajustez ou relancez les tâches si nécessaire.

> **Avant de commencer :** une installation fonctionnelle de V-Ray Standalone et une licence Chaos/V-Ray valide sont nécessaires. V-Raykally est gratuit ; le moteur de rendu et sa licence sont distincts.

## Un fonctionnement local

Les fichiers de rendu et le traitement de la file restent sur votre ordinateur. Les diagnostics par IA s'exécutent localement. Les statistiques d'utilisation facultatives de l'application ne sont activées qu'avec votre consentement ; consultez la [politique de confidentialité](https://v-raykally.adrienlejeune.com/privacy/) pour les détails.

V-Raykally est un **freeware**, utilisable gratuitement pour vos projets personnels, éducatifs et commerciaux, selon son [contrat de licence](LICENSE). Ce dépôt rassemble les téléchargements publics, les notes de version et l'assistance ; le code source de l'application n'y est pas distribué.
